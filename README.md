# Java Calculator

This is a simple console based calculator  that takes **two numbers** and an **operation** from the user, then outputs the result. 
## Features

- Addition (+), subtraction (-), multiplication (*), division (/)
- Handles division by zero safely
- Detects invalid operations and informs the user
- Only prints the result if the operation is valid

## How to View the Code

To view the full Java code:

1. Go to the `Javapractice` folder in this repository.
2. Scroll down and click the **Java Calculator** file (`Calculator.java`).
